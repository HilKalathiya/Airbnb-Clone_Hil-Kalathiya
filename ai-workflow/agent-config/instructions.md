# AI Agent Instructions (Antigravity Context)

During the development of this project, the AI agent (Antigravity) was configured with strict, highly detailed context bounds defining:
1. Exact visual pixel parity rules (no approximations).
2. Pure React + Tailwind rendering constraints without heavily relying on external mapping libraries (e.g., CSS static mapping).
3. Chunk-based linear task execution mapping out the listing interface sequentially.
4. "No Placeholder" rule enforcing complete, functional components over wireframes.

The primary configuration relied on the deep forensic geometry instructions provided in the system prompts for each chunk. The agent was restricted from lifting the original site's source code, generating purely original React structural components.
